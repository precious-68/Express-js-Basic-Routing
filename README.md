Express.js Basic Routing

A beginner-friendly Node.js and Express.js project demonstrating how to create a basic web server and handle multiple routes.

About the Project

This project is a simple Express.js application with three routes: Home, About, and Contact.

It was built to practise setting up an Express server, handling HTTP GET requests, and understanding how routing works in Express.js.

Features

* Starts a web server using Express.js.
* Creates a Home page route (/).
* Creates an About page route (/about).
* Creates a Contact page route (/contact).
* Returns different responses depending on the requested URL.

Technologies Used

* Node.js
* Express.js
* JavaScript

Getting Started

1. Clone the repository

git clone YOUR_REPOSITORY_URL

2. Navigate into the project folder

cd Express-Projects

3. Install dependencies

npm install

4. Start the server

node index.js

The server runs on port 3000.

Available Routes

Route	Description
/	Home
/about	About
/contact	Contact
